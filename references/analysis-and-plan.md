# 分析与方案

对选定商家研究官网首页、核心产品/服务、关于、联系方式、预约/询价路径，以及相关公开评价和自有社交页。
在手机和电脑实际查看关键页面。只检查路径，不向真实业务系统提交订单、预约或表单。
记录时间、来源、事实/推测/未知；截图按当前工具要求保存。

报告包括：
1. 业务与目标顾客。
2. 品牌优点和应保留特色。
3. 有证据的网站问题，按业务相关性排序。
4. 适合 Demo 的一个用户旅程。
5. 可用/缺失素材、来源及使用依据。
6. 公开邮箱及具体来源；缺少时记录联系表单等自有入口。
7. 局限与待确认项。

不凭一次访问失败断言长期故障，不虚构访问量、加载分数、SEO 排名、转化率或收入影响。
提供一个推荐方向，备选仅在有助于选择时给出。用户可接受、修改或自拟方案。
方案明确：目标、页面、视觉、交互、素材、演示边界、交付方式。
默认本地演示，不接真实库存、日历、支付或表单提交；正式站实现建议单独表述。
希望邮件有分享链接时，在方案里写明使用用户可用托管并核实外部访问。
保存 plan 并展示，再记录真实同意；“按推荐做”可接受。实质变更重新保存确认，不复用旧客户或旧版本批准。
批准范围内的普通实现选择自主处理，不为每个颜色和间距增加审批。
